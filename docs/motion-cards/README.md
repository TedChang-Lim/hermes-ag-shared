# 모션그래픽 레퍼런스 카드 (전 식구 공용)

레퍼런스 영상 → 수치 카드로 바꾸는 도구와 결과물. 루나 2026-10-29.

## 도구
```bash
python3 tools/motion/reference-card.py <영상> <출력폴더> <이름> [footage|motion]
```
- `footage` = 실사/강의 영상 (컷 임계값 0.32)
- `motion`  = 모션그래픽 (0.10)

## 추출 항목
컷 타임 · 샷 길이 5분위 · CV(변동계수) · 3초 홀드 비율 · k-means 팔레트 · 밝기/모션 · BPM · 온셋 · 컷-비트 정렬

## 핵심 발견
- 잘 만든 영상의 리듬 지문: **CV 1.5 내외 · 중앙값 < 평균 · 3초 홀드 19~21%**
- **장르가 다르면 CV 비교 금지** (강의 영상 vs 작품 영상)
- **읽기 시간 = 글자수 × 0.25초 + 0.5초** — 중요 텍스트는 반드시 확보. 15초에 문장 3개가 한계.
