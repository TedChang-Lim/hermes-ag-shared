## 📦 생성된 스킬 구조

```
~/.hermes/skills/productivity/hwp-form-automation/
├── SKILL.md                           # 스킬 명세서 (워크플로우, 제약, 검증 체크리스트)
├── scripts/
│   └── hwp_form_automation.py         # 실행 스크립트 (kordoc MCP 연동)
└── templates/
    └── master-profile.yaml            # 마스터님 통합 프로필 (기관별 매핑 포함)
```

### 주요 기능
| 명령 | 기능 |
|------|------|
| `parse 템플릿.hwp` | 필드맵/표구조/서식프로필 추출 → `_parsed/` 캐시 |
| `fill 템플릿.hwp` | 마스터 프로필로 채워 HWPX 생성 (`hwpx-preserve` 모드, 서식 100% 보존) |
| `batch 이력서.hwp 강의계획서.hwp 강사소개.hwp` | 3종 일괄 처리 |
| `verify 출력.hwpx` | PNG 렌더링해 시각 검증 |

## 📋 다음 액션 (마스터님 템플릿 주시면 즉시 실행)

1. **템플릿 3종** (`이력서_양식.hwp`, `강의계획서_양식.hwp`, `강사소개_양식.hwp`) → `~/초보프로젝트/templates/hwp/` 배치
2. 실행:
   ```bash
   python ~/.hermes/skills/productivity/hwp-form-automation/scripts/hwp_form_automation.py batch 이력서_양식.hwp 강의계획서_양식.hwp 강사소개_양식.hwp
   ```
3. 결과물: `~/초보프로젝트/output/hwp/` 에 `*_완성.hwpx` 생성 + PNG 검증본
4. 한컴에서 열어서 필요시 `.hwp`로 저장 (3초)
