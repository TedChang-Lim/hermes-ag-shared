## 💡 1. 재시도(Retry) 보완 루프 개선안

### 현상
- 현재 70점 미만의 'RETRY(보완)'가 뜨면 수강생은 그냥 텍스트창에서 알아서 수정해야 함. '보완' 배지는 눌러지지 않는 단순 상태 라벨임.

### 제안 (AG)
- 채점 결과가 70점 미만일 때 결과창 하단에 **`[✍️ 피드백 반영하여 다시 도전하기]`** 버튼을 노출함.
- 이 버튼을 누르면 AI 피드백 내용을 그대로 유지한 채, 수강생의 입력 포커스를 다시 상단 `textarea`로 부드럽게 스크롤하며 돌려줌. 수강생이 피드백을 보면서 즉시 수정할 수 있도록 유도하여 **완벽한 반복 학습 루프**를 형성.

## 🔒 2. 클래스 인증 코드(Passcode) 보안 시스템 제안

### 현상 및 우려
- 누구나 무제한으로 DeepSeek API 채점을 사용하게 둘 경우 **API 토큰 비용 폭발** 리스크가 있음.
- 공식 교육생(비용 지불 또는 특정 요건 충족자)과 일반 단순 방문객(체험생)의 자격 구분이 안 되어 **수료증의 공신력**이 떨어질 우려가 있음.

### 제안 (AG)
* **2원화 채점 아키텍처 도입**:
  1. **일반 체험 모드 (Sandbox Mode)**:
     - 누구나 접속해 미션 1을 작성해 볼 수 있음.
     - 단, API를 호출하지 않고 로컬 정규식/규칙 기반으로 빠르게 피드백을 주는 **가벼운 로컬 채점 모드**로 동작 (API 비용 $0).
     - 최종 수료증 발급은 비활성화됨.
  2. **정식 교육생 모드 (Exam Mode)**:
     - 강사(마스터님)가 오프라인/온라인 강의실에서만 알려주는 **`[KACEC 클래스 인증 코드]`**(예: `kacec2026`, 일일 변동 가능)를 입력하여 잠금을 해제.
     - 잠금이 풀리면 실제 **DeepSeek V4 Flash API를 통한 정밀 AI 채점**이 활성화됨.
     - 70점 통과 시 **정식 디지털 수료증 발급** 가능.
