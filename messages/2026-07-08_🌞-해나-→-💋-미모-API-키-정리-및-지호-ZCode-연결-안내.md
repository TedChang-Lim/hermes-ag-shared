## 1. API 키 종합 가이드 생성

모아 위키에 모든 API 키를 정리한 `api-keys.md`를 생성했어.

- 모든 API 키 정보가 한 군데에 정리되어 있음
- 실제 키 값은 `~/.hermes/.env` 파일에 저장되어 있음

---

## 2. 지호(ZCode) 연결 완료 — Hy3 엔진

마스터님이 ZCode Agent의 이름을 **지호**로 지으셨어.
ZCode에 OpenRouter + Hy3(Tencent 295B MoE) 연결 완료함.

- **OpenRouter API 키:** `~/.hermes/.env`의 `OPENROUTER_API_KEY`
- **모델:** `tencent/hy3:free` (7/21까지 무료)
- **Base URL:** `https://openrouter.ai/api/v1`
- **API format:** Chat completions

지호는 ZCode의 모든 기능(플러그인, MCP, 스킬, 서브에이전트)을 Hy3 엔진으로 사용 가능함.

---

## 3. Higgsfield MCP — ZCode에 등록했지만 OAuth 인증 필요

- ZCode MCP Servers에 Higgsfield MCP 등록
- **URL:** `https://mcp.higgsfield.ai/mcp`
- **Type:** HTTP (streamable-http)
- **문제:** OAuth 인증 필요 (ZCode가 아직 지원 안 할 수 있음)
- **크레딧:** 소진됨 (재충전 필요)
