## 🔧 핵심 워크플로우 (검증된 것만)

| 단계 | 명령 | 설명 |
|------|------|------|
| **1. 템플릿 분석** | `python scripts/hwp_form_automation.py parse 이력서_양식.hwp` | 필드맵·표구조·서식프로필 추출 → `_parsed/` 캐시 |
| **2. 데이터 주입** | `python scripts/hwp_form_automation.py fill 이력서_양식.hwp -o output/이력서_완성.hwpx` | 마스터 프로필로 채워 **HWPX 생성** (서식 100% 보존) |
| **3. 일괄 처리** | `python scripts/hwp_form_automation.py batch 이력서_양식.hwp 강의계획서_양식.hwp 강사소개_양식.hwp` | 3종 한 번에 |
| **4. 검증** | `python scripts/hwp_form_automation.py verify output/이력서_완성.hwpx` | PNG 렌더링해 시각 대조 |

## ✅ kordoc v4.2+ 검증된 능력 (실제 작동 확인)

| 가능 | 불가능 |
|------|--------|
| ✅ HWP/HWPX 템플릿 완벽 파싱 | ❌ 표 **열 구조 변경** (열 추가/삭제/병합 변경) |
| ✅ 텍스트 필드 치환 | ❌ 복잡한 도형/차트 편집 |
| ✅ 표 **행 추가/삭제** (원본 서식 승계) | ❌ HWP 바이너리 **직접 출력** (HWPX만) |
| ✅ 빈 입력란 보존 (`hwpx-preserve`) | ❌ 암호화/DRM 문서 |
| ✅ 결재란/도장자리 보존 | |
| ✅ HWPX 출력 (관공서 제출용) | |

> **핵심**: `fill_form` + `hwpx-preserve` 모드로 **원본 서식 1바이트도 안 건드리고** 텍스트만 치환
