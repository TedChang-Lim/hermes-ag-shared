### ❌ 미해결 — 미모가 해야 할 일

#### 1. 🔴 카드 겹침 문제 (가장 중요!)
- **AI 실전 퀵스타트** 섹션의 8개 카드가 겹쳐서 보임
- **이번 주 새 AI 실전 레슨** 섹션의 11개 카드도 겹침
- 마스터님: "알아볼 수 없을 정도로 겹친다. 카드 깔끔하게 안 보여"
- CSS가 `.quick-grid`와 `.weekly-grid`에 `display:grid` + `grid-template-columns`로 되어 있지만 렌더링이 깨짐
- 원인 추정: 카드 콘텐츠가 동적 렌더링(`renderQuickstart()`/`renderWeekly()`)되면서 position/z-index 충돌
- 해결 방향: position/z-index 정리, grid gap 조정, fixed height 적용

#### 2. 🟡 버튼 텍스트 변경
- 퀵스타트/위클리 카드의 "📘 자료 내용으로 알아보기" 버튼이 **같은 페이지 내 해당 트랙 모달**로 연결되게 변경 완료 (openTrack(q.track))
- 근데 퀵스타트/위클리 버튼이 몇 개는 아직 외부링크(`window.open`)로 남아있지 확인 필요

#### 3. 🟢 (선택) MATERIAL_DATA 내용 더 풍부하게
- 현재 30개 레슨에 기본적인 태스크/도구/예제/개념만 있음
- 시간되면 실제 실습형 콘텐츠로 보강

## 페이지 구조 참고
- 14개 TRACKS (7개 KACEC + 4개 EduVerse 융합 트랙 + 3개 자격증)
- 각 트랙에 2~4개 레슨
- `const TRACKS` 배열에 트랙 데이터
- `const MATERIAL_DATA` 객체에 30개 레슨 콘텐츠
- `openTrack(id)` → 트랙 모달 오픈
- `openMaterial(title)` → MATERIAL_DATA 찾아서 표시
- `openMat(title)` → openMaterial wrapper (싱글쿼트 이슈 우회용)
